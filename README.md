# Media Dashboard

Утилита для Windows 11 в трее: схема дисплеев с перетаскиванием, выбор звукового выхода и пресеты «дисплеи + звук» одним кликом. Словарь терминов — [GLOSSARY.md](GLOSSARY.md), решения — [docs/adr](docs/adr).

## Как пользоваться

Левый клик по иконке в трее открывает окно, правый — меню: пресеты, язык, автозапуск, выход.

**Дисплеи.** Все изменения сначала попадают в черновик. Чтобы они вступили в силу, нажмите «Применить», после чего у вас будет 10 секунд, чтобы нажать «Оставить», иначе настройки откатятся.

| Действие | Результат |
|---|---|
| Клик по дисплею | выключить (он уходит в «Выключены») |
| Клик по выключенному | включить справа от остальных |
| Двойной клик | сделать основным (выключенный сначала включится) |
| Перетащить на другой дисплей | меню «Дублировать» / «Расширить» (в сторону, куда бросили) |
| Перетащить в пустое место | переставить, плитка прилипнет к ближайшему краю |
| Перетащить в «Выключены» | выключить |
| Клик по имени внутри группы | выключить только этот дисплей |
| Правый клик | «Переименовать», «Разгруппировать», «Это «…»» для неопознанного дисплея |

Пока вы тащите плитку, схема показывает, что произойдёт при отпускании. Над пустым местом подсвечивается место, куда встанет дисплей, а соседи сдвигаются так, как сдвинутся на самом деле; рядом с этим местом плитка слегка примагничивается. Над другим дисплеем подсвечивается он сам и край, к которому пристанет плитка при «Расширить». Над «Выключены» подсвечивается полоса. Если действие запрещено, подсказка под схемой становится жёлтой ещё до отпускания.

**Звук.** Клик по выходу делает его устройством по умолчанию сразу для всех ролей. Правый клик — «Переименовать» или «Скрыть».

**Пресеты.** Кнопка «Сохранить текущее как пресет» сохраняет текущее состояние. Клик по пресету применяет его, перетаскиванием меняется порядок, правым кликом можно перезаписать, переименовать или удалить пресет. Если какое-то устройство из пресета не подключено, применяется всё остальное, а про недостающее появится предупреждение.

Настройки хранятся в `%APPDATA%\MediaDashboard\settings.json`.

## Сборка

Нужен .NET 10 SDK.

```
dotnet test tests/MediaDashboard.Core.Tests
dotnet publish src/MediaDashboard -c Release -o publish
```

Результат — один самодостаточный `publish/MediaDashboard.exe`. Автозапуск записывает в `HKCU\...\Run` путь к exe, из которого включён. Если перенесли exe, включите автозапуск заново в меню трея.

## Устройство

- `src/MediaDashboard.Core` — домен без зависимостей от Windows: Расположение, операции Черновика, Пресеты, настройки. Покрыт тестами.
- `src/MediaDashboard.Platform` — Win32/COM: CCD API для дисплеев, Core Audio + `IPolicyConfig` для звука, автозапуск.
- `src/MediaDashboard` — WPF-интерфейс и иконка в трее.
