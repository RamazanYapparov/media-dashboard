# C# / .NET 10 + WPF вместо Electron или Tauri

Всё ядро приложения работает через Win32 и COM. Дисплеи настраиваются через CCD API (`QueryDisplayConfig`/`SetDisplayConfig`), звуковой выход по умолчанию меняется через недокументированный `IPolicyConfig`. На C# эти вызовы делаются напрямую через P/Invoke и COM interop, а иконка в трее и Canvas с перетаскиванием есть в WPF без сторонних слоёв. Берём .NET 10, а не 8: поддержка .NET 8 LTS заканчивается в ноябре 2026, а у .NET 10 LTS — в ноябре 2028.

## Considered Options

- **Electron.** Node на машине уже есть, но для Win32/COM понадобился бы нативный аддон или отдельный вспомогательный процесс. Кроме того, это около 100 МБ RAM ради приложения в трее.
- **Tauri.** Приложение было бы лёгким, но COM interop из Rust заметно многословнее, а Rust на машине не установлен.
