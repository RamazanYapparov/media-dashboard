# Дисплей опознаётся по порту видеокарты, а не по EDID

Два `Mi Monitor` отдают одинаковый EDID (`XMI27B1`), поэтому по модели или серийному номеру их не различить. Пресеты ссылаются на Дисплей по порту видеокарты (target id в CCD). Расположение на рабочем столе для этого не подходит: оно меняется при каждой перестановке.

## Consequences

Если переткнуть кабели, Дисплеи становятся Неопознанными, и Пресеты, которые на них ссылаются, нельзя применить, пока пользователь заново не назначит Имена.
